# VLSI RTL Design & Verilog Portfolio

This repository documents my hands-on journey in **Digital Design, RTL Design, and VLSI** using **Verilog HDL and AMD Vivado(2026.1 version)**.

## Overview

* Developing synthesizable RTL designs using Verilog HDL.
* Creating testbenches for functional verification.
* Simulating designs using AMD Vivado.
* Analyzing simulation waveforms to verify functional correctness.
* Performing synthesis and studying RTL/schematic results.
* Documenting design methodology, verification results, and observations.
* Progressively working towards more complex RTL and hardware-design projects.

## Design Flow

**Specification → RTL Design → Testbench → Simulation → Waveform Analysis → Synthesis → Design Analysis**
